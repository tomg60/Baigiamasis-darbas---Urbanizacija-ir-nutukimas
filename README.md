# Baigiamasis darbas: urbanizacija ir nutukimas

Šioje GitHub saugykloje pateikiamas R kodas, naudotas baigiamojo darbo skaičiavimams.

## Failai

- `BD_kodas.R` – pagrindinis R skriptas.
- `data/duomenys_nutukimas.xlsx` – nutukimo duomenys.
- `data/urbanizacija_duom.xls` – urbanizacijos duomenys.
